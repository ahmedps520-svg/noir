# NOIR AI + App Check development setup

NOIR uses Firebase AI Logic through `@react-native-firebase/ai` and the Gemini Developer API backend.

## What this version adds

NOIR now initializes React Native Firebase App Check with:

- **Debug provider in development builds** (`__DEV__`)
- **App Attest with DeviceCheck fallback in production**
- Automatic App Check token refresh
- A forced debug-token request during development so the token is printed in the development logs

The debug token is NOT stored in the project.

## Firebase Console

1. Open **Firebase Console → App Check → Apps**.
2. Find **NOIR (`com.noir.cosmos`)**.
3. Open **Manage debug tokens**.
4. Keep this page ready. You will register the token after the development app launches.

## Generate the debug token

The token is generated by the development build. Firebase's Apple-platform documentation says the debug provider generates a local token when the app launches; that token must then be registered in **Manage debug tokens**. citeturn0search0

Run the iOS development build and watch the development logs. NOIR also prints:

`FIREBASE APP CHECK DEBUG TOKEN: ...`

Copy that token into Firebase Console → App Check → NOIR → Manage debug tokens.

**Treat the token as private. Do not commit it to Git or use it in a production build.** Firebase explicitly warns that a debug token can grant backend access from an unverified device. citeturn0search0turn0search3

## Commands

After extracting this ZIP:

```cmd
npm install
```

You do NOT need to run `eas build:configure` again.

For an iOS development build, once Apple Developer setup is available:

```cmd
eas build --platform ios --profile development
```

The Firebase AI module is native, so the actual AI request needs an iOS development build rather than Expo Go.

## Production

Development uses the debug provider only. Production switches to:

`appAttestWithDeviceCheckFallback`

Do not ship the debug provider or debug token in the App Store build. Firebase recommends using a real production attestation provider for released apps. citeturn0search6turn0search8

The NOIR+ paywall is still test-mode at this stage; real Apple subscription/entitlement verification is a separate step before App Store release.
